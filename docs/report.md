# گزارش پروژه PAWLY
 ۱. معرفی پروژه
PAWLY یک پلتفرم با هدف حمایت از حیوانات خانگی، تسهیل فرایند سرپرستی و ایجاد ارتباط میان دوستداران حیوانات است.
 ۲. امکانات اصلی پروژه
- سرپرستی و واگذاری حیوانات
- جست‌وجو و فیلتر حیوانات بر اساس نوع، نژاد، جنسیت و شهر
- ثبت آگهی حیوانات گمشده و پیدا شده
- ارائه مطالب آموزشی درباره نگهداری حیوانات
- ثبت درخواست سرپرستی
- حمایت و کمک‌رسانی به حیوانات نیازمند
 ۳. اهداف پروژه
- حمایت از حیوانات بی‌سرپرست
- افزایش آگاهی درباره نگهداری حیوانات
- تسهیل ارتباط میان افراد و مراکز حمایت از حیوانات
- فراهم کردن بستری مناسب برای واگذاری حیوانات
 ۴. ساختار تیم
نام گروه: WD Group 12

نام پروژه: PAWLY
 ۵. ابزارها و بستر توسعه

- HTML، CSS و JavaScript برای توسعه رابط کاربری
